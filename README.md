# Radar de Tendências — Evidence-Based Trend Intelligence

> Streamlit prototype that aggregates signals from academic, consulting, institutional, news and corporate sources to support technology and market-trend monitoring.

**Portfolio focus:** Web Data Collection · Trend Intelligence · Source Aggregation · Information Synthesis · Decision Support

## Business Problem

Technology and market teams face a high volume of fragmented information. A useful trend radar should not depend on a single source or perspective.

This prototype organizes signals across multiple source categories and presents them as an evidence-oriented intelligence workflow.

## Source Perspectives

The application currently monitors source groups such as:

- academic research;
- consulting;
- international organizations;
- technology news;
- corporate research.

The objective is to compare signals across perspectives rather than treat one source as definitive.

## Analytical Flow

`Source Collection → Parallel Retrieval → Normalization → Signal Organization → Trend View → Human Interpretation`

## Technology Stack

Python · Streamlit · Requests · Concurrent Retrieval · HTML/CSS

## Limitations

Web sources change over time and may block automated retrieval. The application should be treated as a research/monitoring prototype rather than a complete forecasting system.

Trend signals also require human validation: source quality, publication date, methodological strength and independence should be assessed before strategic decisions.

## Portfolio Perspective

**Information retrieval → source triangulation → trend intelligence → decision support**

This project complements the portfolio's ML/RAG work by showing the upstream intelligence problem: finding and structuring external evidence before applying deeper AI reasoning.
